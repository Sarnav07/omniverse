New result Gaussian pm-AMM Deriving λ* from scratch
Step 1 — reserve parametrisation
x̃(z) = φ(z) − z·Φ(−z) [NO reserves per unit L] ỹ(z) = φ(z) + z·Φ(z) [YES reserves per unit L] z = (y−x)/L [pool's internal state] P = Φ(z) [quoted probability]

Both reserve functions are smooth, strictly monotone, and satisfy ỹ(z) − x̃(z) = z exactly.

Step 2 — PA-AMM rebalancing on the Gaussian invariant
Active: (λx_n, λy_n, λL_n) → same z_n, same price, λ× depth Passive: ((1−λ)x_n, (1−λ)y_n, (1−λ)L_n) → locked After arbitrage moves active pool to z_true,n+1: y_total = λL·ỹ(z_true) + (1−λ)L·ỹ(z_n) x_total = λL·x̃(z_true) + (1−λ)L·x̃(z_n) New internal state: z_{n+1} = (y_total − x_total)/L = λ·z_true,n+1 + (1−λ)·z_n

This is exact — no approximation. The linearity of (y−x) in reserves makes the z-dynamics linear by construction.

Step 3 — gap process (exactly AR(1), no linearization)
Define gap: gᶻ_n = z_true,n − z_{n−1} From Step 2: z_n = λ·z_true,n + (1−λ)·z_{n−1} Therefore: gᶻ_{n+1} = z_true,n+1 − z_n = z_true,n+1 − λ·z_true,n − (1−λ)·z_{n−1} = (z_true,n+1 − z_true,n) + (1−λ)·(z_true,n − z_{n−1}) = εᶻ_{n+1} + (1−λ)·gᶻ_n → gᶻ_{n+1} = (1−λ)·gᶻ_n + εᶻ_{n+1} ✓ exact AR(1)

For G3M this AR(1) is only a linearization. For the Gaussian invariant it is exact. This is a stronger result.

Step 4 — stationary gap variance (exact)
E[(gᶻ)²] = Var(εᶻ) / (λ(2−λ)) = σᶻ²·Δt / (λ(2−λ)) Same structural form as G3M. σᶻ² = variance of z-space innovations per unit time.
Step 5 — tracking error and LVR in z-space
Tracking error (probability miscalibration): TEn = (Φ(z_n) − Φ(z_true))² ≈ φ(z_true)²·(1−λ)²·(gᶻ_n)² Incremental LVR (active pool, second-order Taylor): LVRn ≈ (λ/2)·φ(z_true)/v(z_true)·(gᶻ_n)² where: v(z) = φ(z) + z·(2Φ(z)−1) [pool value per unit L at fair price]
Step 6 — Bellman equation and optimal λ* (closed form)
One-stage cost: Cn = TEn + γ'·LVRn ∝ [φ(z)²·(1−λ)² + γ'·φ(z)/(2v(z))·λ] · (gᶻ)² Define: γ_G(z) = γ' / (2·v(z)·φ(z)) ← probability-dependent! Same Bellman structure as G3M → same closed-form solution: λ*(P_true) = (1 + √(1 + 2γ_G)) / (1 + γ_G + √(1 + 2γ_G)) where z = Φ⁻¹(P_true), γ_G = γ'/(2·v(z)·φ(z))

The formula is the same as G3M. Only γ changes — and now it is a function of the current market probability P_true, making λ* dynamic.
